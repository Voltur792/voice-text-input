# Vosk. Deliberately light and wide-pinned: Astra installs it as ONE flat set

# Python, an old interpreter, a broken download) used to leave the plugin
# without astra_plugin_sdk — it then died at import time with
# ModuleNotFoundError and never reached its own self-healing code.
# faster-whisper (the ctranslate2/av/onnxruntime chain, ~200 MB) is no longer
# here: src/deps.py installs it on demand when the whisper engine is used, and
# dictation runs Vosk-only without it.
